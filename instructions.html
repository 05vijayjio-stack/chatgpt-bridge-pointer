## The Goal
Fast, continuous back-and-forth with ChatGPT to move a coding/automation project forward:
- Planning/direction needed → get a ready-to-paste plan/doc from ChatGPT (not prose describing what a plan should contain — the actual plan text).
- Code needed → get a real, complete, copy-paste-ready code snippet (not a description of code).
- After every ChatGPT reply, automatically ask it for the next concrete, ready-to-use prompt: "Based on everything so far, give me the exact next prompt for Claude Code — concrete, ready to paste, with any needed context or file contents included as plain text. If this step is planning, write it as a ready-to-paste document. If this step is code, give me the exact code as a copy-paste-ready snippet." Execute it.
- Gently nudge ChatGPT away from over-planning: if it drifts into "let's think about this more" when there's already enough to build, say "We have enough context now — give me the actual implementation step, not more planning." Balance — real planning when a step genuinely needs it, but default to momentum.
- Close the loop: after executing, before asking for the next step, tell ChatGPT briefly what happened (succeeded/failed, key output, errors) so its next suggestion is grounded, not blind.
- Keep looping continuously — no pauses for approval on ordinary steps, including risky-looking ones (security, destructive changes). The user interrupts manually with "stop"/"pause" if needed.
